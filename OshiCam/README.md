# 推しカメ (OshiCam)

コンサート中のアーティスト（推し）を **自動で追いかけて撮る** iPhone 用カメラアプリです。
ジンバルなどの機材は不要で、iPhone を三脚や一脚に固定しておけば、アプリが推しを追いかけて画角を決めてくれます。

> ⚠️ 撮影・録音は必ず公演のルールに従ってください。撮影 OK の公演・リハーサル・自分たちのライブなどでどうぞ。

## できること

- **タップで推しをロック**：人物を自動検出して枠を表示。タップした人を追尾します（指でなぞって範囲を指定することもできます）
- **自動追尾（バーチャルカメラマン）**：4K で撮影し、その中から推しの周りを滑らかに切り出して 1080p で録画
  - 少し動いたくらいでは画面を動かさない「あそび（デッドゾーン）」
  - 臨界減衰バネによる、カクつかずオーバーシュートもしないカメラワーク
  - 推しの移動速度から少し先を予測して、追尾の遅れを補正
- **見失っても自動で復帰**：人物検出と「見た目の特徴量」を使って、さっきまで追っていた人を探し直します。見つからない間はゆっくり引きの画に戻ります
- **出力の縦横比**：16:9 / **9:16（縦動画、SNS 向け）** / 1:1。横向きの 4K から縦動画を切り出せます
- **フレーミング**：全身 / 上半身 / 手動（ズーム倍率を固定）
- **露出・ピントを推しに合わせ続ける**：スポットライトで白飛びしにくくなります。露出補正もできます
- **光学ズーム**：0.5× / 1× / 3×（5×）のレンズ切り替えとピンチズーム
- 録画した動画は **写真アプリに自動保存**（HEVC .mov、音声つき）
- 小窓（PiP）に「録画される映像」を常に表示。タップでメイン画面と入れ替え

## 仕組み

```
 カメラ (4K, 30fps) ──┬─▶ 縮小 (1080p) ──▶ 全体プレビュー
                      │        │
                      │        └─▶ SubjectTracker (Vision, 別スレッド)
                      │              ・VNTrackObjectRequest で毎フレーム追尾
                      │              ・0.5秒ごとに VNDetectHumanRectanglesRequest で枠を補正
                      │              ・見失ったら人物検出 + VNGenerateImageFeaturePrint で再識別
                      │                     │ 推しの位置・速度
                      │                     ▼
                      └─▶ 切り出し (Core Image / GPU) ◀── VirtualCamera
                               │                          ・デッドゾーン + 先読み
                               │                          ・臨界減衰バネで位置とズームを追従
                               ├─▶ 出力プレビュー
                               └─▶ MovieRecorder (AVAssetWriter, HEVC 1080p)
```

追尾（Vision）は別スレッドで非同期に動くので、処理が重くなっても録画のフレームは止まりません。

## ビルド方法

必要なもの

- Mac + **Xcode 16 以降**
- **iPhone（iOS 17 以降）実機**（シミュレーターにはカメラがないため動きません）
- 望遠レンズ付きの Pro 系 iPhone だとより快適です

手順

1. `OshiCam/OshiCam.xcodeproj` を Xcode で開く
2. ターゲット **OshiCam** → **Signing & Capabilities**
   - **Team** に自分の Apple ID（Personal Team で OK）を設定
   - **Bundle Identifier** を `com.あなたの名前.oshicam` など他と被らないものに変更
3. iPhone を Mac につないで実行先に選び、▶︎（⌘R）でビルド＆実行
4. 初回は iPhone 側で「設定 → 一般 → VPN とデバイス管理」から開発元を信頼し、「デベロッパモード」をオンにする必要があります

## 使い方

1. iPhone を **横向き**（Dynamic Island が左）にして起動
2. レンズボタン（0.5 / 1 / 3 …）やピンチで、ステージ全体が入るくらいに合わせる
3. 点線の枠で表示される人の中から、推しを **タップ**（うまく検出されないときは指で囲む）
4. 枠が緑になったら追尾中。小窓に出ているのが録画される映像です
5. 赤いボタンで録画開始 / 停止 → 写真アプリに保存されます

| 表示 | 意味 |
| --- | --- |
| 緑のカギ括弧 | 追尾中の推し |
| オレンジの点線 | 見失った（最後に見えた位置）。自動で探し直し中 |
| 白い枠＋外側が暗い | 録画される範囲 |
| 右下の ✕ | ロック解除 ／ ◎ 画面中央の人をロック |

### きれいに撮るコツ

- **望遠レンズ（3× / 5×）でステージ全体を画面に入れる** → アプリに推しを切り出させる、のが一番高画質です（切り出し前の画が 4K なので、2 倍程度までの切り出しなら 1080p の解像感が保てます）
- スマホは三脚・一脚・クリップなどで固定するのがおすすめ。手持ちなら「手ぶれ補正」をオンに
- スポットライトで顔が白飛びするときは、設定の「露出補正」をマイナス（-0.7〜-1.3 EV くらい）に
- 4K の処理と録画を続けるので本体がかなり熱くなります。長時間撮るならモバイルバッテリー・空き容量の確保を。高温の警告が出たら休ませてください

## 現時点の制限

- 画面の向きは **横向き（landscapeRight）固定**
- 出力は 1080p / 30fps（元の 4K 映像は保存しません）
- 人物検出が効きにくい暗いシーン・着ぐるみなどは「指で囲む」でロックしてください（この場合、見失ったときの自動復帰は位置ベースのみ）
- メンバーが重なったり、衣装が同じだったりすると別の人に乗り移ることがあります。そのときはタップし直してください
- Linux 環境で作成したため、**まだ Xcode でのビルドと実機での動作確認をしていません**。最初のビルドでエラーが出たら内容を教えてください

## 今後のアイデア

- **DockKit 対応**：対応する電動スタンド／ジンバルに載せると、追尾結果でスマホ自体を首振りさせて、より広い範囲を追える
- **後処理モード**：4K の元映像をそのまま保存し、撮影後に推しを選び直して切り出し（先の動きも見えるので、さらに滑らかなカメラワークにできる）
- 複数メンバーの切り替え（ダブルタップで次の人へ）
- 顔・骨格（VNDetectHumanBodyPoseRequest）を使った、より賢いフレーミング
- 4K 出力・60fps・両方向の横向き対応
